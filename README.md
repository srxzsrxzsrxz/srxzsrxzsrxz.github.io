# srxzsrxzsrxz.github.io

Jekyll blog hosted on GitHub Pages → https://srxzsrxzsrxz.github.io

## Update from PC
```bash
./new-post.sh "My Post Title"   # creates _posts/YYYY-MM-DD-my-post-title.md
git add . && git commit -m "new post" && git push
```
The site rebuilds automatically in ~1 minute.

## Edit on mobile
- **Pages CMS** (recommended): open https://app.pagescms.org → sign in with GitHub → pick this repo.
- **GitHub app / github.com**: open `_posts/`, tap a file → ✏️ edit → commit.

After editing on mobile, run `git pull` on PC before editing locally.

## Images
Put images in `assets/images/` and use `![alt](/assets/images/photo.jpg)`.
